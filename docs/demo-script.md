# Reclaim three-minute demo script

Target recording length: **2 minutes 50 seconds**, with 10 seconds of margin under the three-minute limit. The spoken script is 328 words. Rehearse with the screen actions; narration speed alone does not determine runtime.

## Prepare before recording

- Open the home page, the architecture graphic, a seller browser profile, a separate buyer browser profile, and the S3 console. Sign in before recording.
- Use test identities and a clearly labelled demonstration listing. Redact emails, phone numbers, account IDs and all credentials.
- Prepare a photo whose real Bedrock analysis has already succeeded. Keep the resulting editable suggestions open so the recording does not spend up to 40 seconds waiting. Do not present mocked suggestions as live AWS output.
- Have the pickup details ready, choose a future pickup time, and rehearse the item name used in buyer search. Test contact visibility and both histories beforehand.
- Show the uploaded object's preview in the actual S3 console briefly. A diagram alone does not demonstrate working AWS integration.
- For the completion step, say that pickup is being simulated. Do not mark a real, uncollected customer's item complete for the recording.
- The active provider is `MAIL_PROVIDER=smtp`: Nodemailer sends email. SES is implemented as an optional adapter, not the active email service. Keep this distinction in the narration.

## If an action takes longer

Use a short, clearly explained cut between seller and buyer sessions. Cut loading time, not the evidence of acceptance or completion. The recording may use prepared data, but distinguish prepared results and simulated pickup from live actions. If real photo analysis fails, show the manual fallback and describe the failure honestly.

## Export and submit

Watch the exported video from start to finish and confirm it is no longer than three minutes. Upload it to YouTube as public or unlisted. Open the link in a signed-out browser, then paste the working video URL into the submission form. Ensure the actual AWS integration is visible, narration is audible, and private data is not readable.
